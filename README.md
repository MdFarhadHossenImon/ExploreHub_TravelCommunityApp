# ExploreHub Flutter

Flutter implementation of the ExploreHub traveler community app.

## Architecture

- `lib/backend`: models, repositories, and services
- `lib/frontend`: app shell, routing, theme, widgets, and feature screens

## Included screens

- Onboarding
- Auth hub
- Login
- Sign up
- Forgot password
- OTP verification
- Community feed
- Discover trips
- Hotel booking
- Ticket booking
- Saved items
- Profile
- Create post

## Notes

- The current backend is mock-data driven but already separated behind repositories so a real API can be attached later.
- Package versions were selected from current pub.dev package pages on April 10, 2026.
- Flutter SDK is not installed in this environment, so the project could not be generated or executed locally here.
